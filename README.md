# reviewpipe

> Status: pre-alpha, scaffolding only. See `CLAUDE.md` and `docs/DEV_GUIDE.md`
> for the build plan.

A pipeline framework for analyzing e-commerce customer reviews — sentiment,
recurring themes, and trends — with pluggable input formats and pluggable
models (zero-dependency lexicon, local transformers.js, Hugging Face hosted,
or bring your own frontier model).

Full documentation will land here once Phase 12 of the build plan is
complete.
